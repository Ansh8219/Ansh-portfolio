# NorthVaultStudios Website
🚀 NorthVaultStudios — Building the future

A futuristic, glassmorphism-themed website for NorthVaultStudios digital agency.

## Features

- 🎨 Futuristic glassmorphism design with neon gradients
- 📱 Fully responsive (mobile + desktop)
- ⚡ Smooth animations with Framer Motion
- 🌟 Floating particle background
- 🎯 Parallax hero section
- 💎 Glass blur effects
- ✨ Glow-on-hover animations

## Tech Stack

- React 18
- Vite
- TailwindCSS
- Framer Motion
- React Router

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Pages

- `/` - Landing/Home page
- `/services` - Services overview
- `/about` - About Us page
- `/contact` - Contact page
